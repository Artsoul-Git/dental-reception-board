# 受付予約ボード（歯科医院向け 予約・患者管理）デモ

歯科医院の受付カウンターで使う、予約と患者さんの管理画面のデモです。

- **公開URL**：https://ccbox.artsoul.jp/dental-reception-board/
- 閲覧にはパスワードが必要です

## これは動作デモです

- 実在する歯科医院のものではありません。医院名・お電話番号は仮のものです
- 表示されている氏名・診察券番号・メールアドレス・ご予約は**すべて架空のサンプル**です。実在の人物とは関係ありません
- 入力された内容はお使いのブラウザの中だけに保存され、どこにも送信されません
- **メールは実際には送信されません。** 文面を組み立てて送信ログに残すだけです
- 「設定・連携 → デモを初期状態に戻す」で、いつでも元に戻せます

デモデータは開いた日を起点に、過去3か月ぶんと先1か月ぶんを自動で組み立てます。

## 触れる画面

日別ボード／週間の埋まり／月間の空き／患者台帳／お知らせ・案内／分析／設定・連携
